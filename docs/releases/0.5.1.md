Лабиринт и Библио-Глобус находят книги.

- Лабиринт иногда возвращал пустой результат, хотя книги на странице были: программа принимала его фразу «Пока не нашли для себя ничего в Лабиринте?» за «ничего не найдено».
- Библио-Глобус открывал вместо результатов страницу «404»: его поиск работает только через поле поиска на главной странице. Теперь программа ищет там так же, как человек.
- Программа ждёт ссылок именно на книги, а не на любой раздел магазина, и даёт медленным магазинам (Республике) чуть больше времени.
