Подготовка к новым магазинам. Программа сама предложит обновиться.

В «Справка» → «Проверить площадки» добавлена разведка магазинов, которых ещё нет в поиске: Республика, Буквоед, Дом книги (СПб), Московский дом книги, Библио-Глобус, Book24 и Лабиринт. Программа открывает главную страницу каждого, ищет книгу через поле поиска по ISBN и по названию и сохраняет снимки страниц — по ним будет написан разбор, и магазины войдут в обычный поиск следующим обновлением.

Обычный поиск цен эта версия не меняет. Проверка площадок стала дольше — на 3–4 минуты.
