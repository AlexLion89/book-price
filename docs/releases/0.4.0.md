Отметки экземпляра и оценки читателей с LiveLib и ЛитРес. Ставится кнопкой «Обновления».

**Отметки экземпляра.** На странице книги, под состоянием, — галочки:

| Отметка | Цена |
|---|---|
| С автографом автора | +30 % |
| Первое издание | +15 % |
| В футляре или подарочной коробке | +10 % |
| Суперобложка на месте | +5 % |
| Библиотечные штампы | −15 % |
| Дарственная надпись или чужие пометки | −10 % |

Отметки описывают именно этот экземпляр, поэтому меняют и начальную цену, и нижний предел (вместе не больше +60 % и не меньше −40 %). Они же попадают в текст объявления: «Особенности: с автографом автора», а минусы — честной строкой «Честно: есть библиотечные штампы». Для известных авторов автограф может стоить в разы дороже — такие случаи лучше проверить отдельно.

**Оценки читателей.** К досье добавлены LiveLib и ЛитРес: программа один раз на книгу открывает их в окне поиска, находит книгу и читает рейтинг и число оценок. Надбавка за спрос берётся по самому сильному из источников (FantLab, LiveLib, ЛитРес, Читай-город). Чтение этих сайтов пока проверено только на образцах разметки — нажмите «Справка» → «Проверить площадки», и по снимкам поправлю, если что-то не так.
