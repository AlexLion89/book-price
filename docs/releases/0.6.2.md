Браузер можно выбрать в «Справке»; на Mac больше не появляется лишнее пустое окно Chrome.

- **Выбор браузера**: «Справка → Браузер» — список подходящих браузеров на компьютере (Edge, Chrome, Яндекс, Brave,
  Vivaldi). Поиск переходит на выбранный со следующей книги, окно программы — после перезапуска (кнопка там же).
  Если выбранный браузер потом удалят — программа возьмёт следующий.
- **Mac: лишнее пустое окно.** Щелчок по значку Chrome окна программы в Dock заставлял Chrome открыть пустую вкладку
  в новом окне — теперь программа сразу закрывает такие окна в своей копии браузера. Ссылки на магазины, которые вы
  открываете из программы, не трогаются.
- **Mac: запуск без настроек безопасности** — в инструкции ниже появилась одна команда для Терминала вместо
  «Конфиденциальность и безопасность → Всё равно открыть».

Система: Windows и macOS
