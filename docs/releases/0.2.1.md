Программа теперь называется **«Ценитель»** — лисья оценка книг для Авито. Ставится кнопкой «Обновления».

- На главной — иллюстрация: лиса-читательница в кресле с детективом.
- Значок лисы в очках — в окне программы и на ярлыке; ярлык на рабочем столе сам переименуется в «Ценитель».
- Обновлена инструкция (`BookPrice-instruction.pdf`).

Значок самого файла `BookPrice.exe` меняется только в новом архиве ниже; после обновления кнопкой ярлык всё равно будет с лисой.
