Работает с Chrome, Edge или Яндекс Браузером, а на Windows реже тревожит антивирус.

- **Браузер — какой установлен**: Edge, Google Chrome, Яндекс Браузер, Brave или Vivaldi. Если на компьютере только
  Safari или Firefox — программа скажет, какой браузер поставить, и даст ссылки.
- **Ваши окна и вкладки не трогаются**, даже если это тот же браузер: у программы свои окна со своим профилем, и
  закрывает она только их. Теперь окно считается своим, только если оно и правда работает на профиле программы.
- **Windows — меньше поводов для антивируса**: своё окно программа ищет средствами Windows, без запуска PowerShell
  при каждом старте; ярлык создаётся без обхода политики сценариев. Ниже — как один раз добавить папку программы
  в исключения антивируса.
- **Mac**: программа к нему готова — одна для Intel и Apple M, macOS 12 и новее. Сама сборка для Mac придёт
  следующим выпуском; как её поставить, уже описано ниже.
- В «Справке» — кнопка «Проверить окно поиска»: открывает окно поиска на несколько секунд, без захода на сайты.
- Заново скачанная программа больше не запускает старый код, оставшийся от прошлой установки.
- Обновления приходят по системам: исправление только для Mac не перезапустит программу на Windows, и наоборот.

Система: только Windows
