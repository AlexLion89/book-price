Первая версия — для проверки дома.

**Как установить:** скачайте `BookPrice-0.1.0.zip`, распакуйте его (правой кнопкой → «Извлечь все…») и откройте `BookPrice.exe` в распакованной папке. Windows один раз предупредит — «Подробнее» → «Выполнить в любом случае». На рабочем столе появится ярлык «Цена книги». Подробно, с картинками — в `BookPrice-instruction.pdf`.

**Проверено:** справочники FantLab и Читай-город, цены Читай-города и букинистов alib на живых данных; запуск, ярлык, управление Edge, отчёт об ошибке, проверка обновлений.

**Не проверено на настоящих страницах:** Авито, Озон, Wildberries, Яндекс Маркет — нужна проверка с домашнего интернета: «Справка» → «Проверить площадки», получившийся zip с рабочего стола прислать разработчику.
