# Ценитель

Лисья оценка книг для Авито.


Программа для Windows и macOS: вводишь книгу — она смотрит цены в магазинах и на Авито и подсказывает,
за сколько выставить объявление и как снижать цену, если книга не продаётся.

Поиск идёт с компьютера пользователя через его браузер: Авито и магазины пускают обычных
посетителей, а серверы — нет. Никакого ИИ: издание определяется по ISBN, объявления отбираются
фильтром, сомнительные человек отмечает сам.

**Скачать**: [последний выпуск](https://github.com/AlexLion89/book-price/releases/latest) — архив для Windows и
инструкция с картинками (PDF, Windows). Пробная версия для Mac (`…-mac.dmg`) и другие пробные выпуски — на странице
[всех выпусков](https://github.com/AlexLion89/book-price/releases).

## Как установить

Нужен один из браузеров: **Google Chrome, Microsoft Edge или Яндекс Браузер** (подойдут и Brave, Vivaldi).
Программа сама находит установленный и открывает в нём свои отдельные окна со своим профилем — ваши окна,
вкладки и пароли она не трогает. Если подходящих браузеров несколько, нужный выбирается в программе: «Справка →
Браузер». Safari и Firefox программа не умеет: если на компьютере только они, без
одного из браузеров выше она работать не сможет — скачайте [Chrome](https://www.google.com/chrome/),
[Edge](https://www.microsoft.com/edge/download) или [Яндекс Браузер](https://browser.yandex.ru/).

### Windows 10 и 11

1. Скачайте `BookPrice-<версия>.zip` — внизу страницы выпуска, в разделе «Assets».
2. Создайте папку для программы, например «Документы\Ценитель». **Если на компьютере антивирус — сразу добавьте
   эту папку в его исключения** (как — ниже): иначе он может удалять файлы при распаковке и спрашивать про каждый.
3. Правой кнопкой по архиву → «Извлечь всё…» → выберите эту папку.
4. Откройте `BookPrice.exe`. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» →
   «Выполнить в любом случае». Это один раз. На рабочем столе появится ярлык «Ценитель».

**Если ругается антивирус.** У программы нет платной цифровой подписи, а собрана она тем же инструментом, что и
многие небольшие программы, — антивирусы относятся к таким с подозрением. Вместо того чтобы разрешать каждое
срабатывание, один раз добавьте папку программы в исключения:

- **Защитник Windows**: «Пуск» → «Безопасность Windows» → «Защита от вирусов и угроз» → «Параметры защиты от
  вирусов и других угроз: Управление настройками» → внизу «Исключения: Добавление или удаление исключений» →
  «Добавить исключение» → «Папка» → папка программы. Если файл уже убран — там же, «Журнал защиты» → запись про
  BookPrice → «Действия» → «Восстановить» или «Разрешить на устройстве».
- **Касперский и другие**: в настройках найдите «Исключения» или «Доверенная зона» и добавьте папку программы.
- Если антивирус заговорит после обновления — добавьте так же папку данных: вставьте `%LOCALAPPDATA%\BookPrice`
  в адресную строку Проводника, чтобы её открыть.

### macOS (пробная версия)

Подходит любой Mac на macOS 12 или новее — и с процессором Intel, и с Apple M: программа одна.

1. Скачайте `BookPrice-<версия>-mac.dmg` (внизу страницы выпуска, в «Assets») и откройте его двойным щелчком.
2. В открывшемся окне перетащите «Ценитель» на папку «Программы» (Applications).
3. Откройте «Ценитель» из Launchpad или Finder → «Программы». В первый раз macOS скажет, что не может проверить
   программу: у неё нет платной подписи Apple. Разрешить один раз:
   - **macOS 15 и новее**: нажмите «Готово», откройте меню Apple → «Системные настройки» → «Конфиденциальность и
     безопасность», пролистайте вниз до строки про «Ценитель» → «Всё равно открыть» → пароль от Mac → «Открыть».
   - **macOS 12–14**: в «Программах» щёлкните по «Ценителю» правой кнопкой (или с Control) → «Открыть» → «Открыть».
   - **Или одной командой** — вместо обоих способов выше: откройте «Терминал» (Launchpad → «Другие» → «Терминал»),
     вставьте строку и нажмите Enter:

     ```
     xattr -dr com.apple.quarantine "/Applications/Ценитель.app"
     ```

     Она снимает с «Ценителя» отметку «скачано из интернета», по которой macOS и спрашивает. Касается только этой
     программы; повторять — только если скачаете новый `.dmg` (обновления программа ставит сама).
4. Откроется окно программы в вашем браузере. Своего значка в Dock у программы нет: её окно — это окно браузера.
   Закрыли окно — программа выключилась.

Отчёт об ошибке и проверка площадок на Mac не кладутся на рабочий стол (macOS спросила бы на это разрешение):
программа сама откроет Finder с готовым файлом.

Данные (книги, цены, журнал) лежат отдельно от программы: на Windows — `%LOCALAPPDATA%\BookPrice`, на Mac —
`~/Library/Application Support/BookPrice`.

## Для разработки

- `bookprice/pricing.py` — правило цены и график снижения.
- `bookprice/matching.py` — «то же издание или нет» для объявлений.
- `bookprice/catalog.py` — карточка книги по ISBN (FantLab + Читай-город) и поиск изданий по названию.
- `bookprice/sources/` — по модулю на площадку: `chitai_gorod`, `alib`, `fantlab` (HTTP),
  `avito`, `shops` (в Edge: маркетплейсы Озон, Wildberries, Маркет и книжные Лабиринт, Book24, Буквоед,
  Республика, Библио-Глобус, Дом книги СПб, Московский дом книги), `extract` — разбор внутри страницы.
- `bookprice/value.py` — досье и надбавка за редкость (давно не переиздавалась, мало объявлений, спрос
  по рейтингу FantLab/Читай-города, коллекционные признаки), только к начальной цене, не больше +50 %.
- `bookprice/copymarks.py` — отметки экземпляра (автограф, первое издание, штампы…): к старту и пределу.
- `bookprice/sources/ratings.py` — оценки читателей LiveLib и ЛитРес через окно поиска (schema.org aggregateRating),
  один раз на книгу.
- `bookprice/search.py` — обход площадок и вердикт; `browser.py` — окно поиска, капча, снимки
  (закрывается после каждого поиска).
- `bookprice/browsers.py` — какой браузер вести: установленный Edge, Chrome, Яндекс, Brave, Vivaldi или Chromium
  (Safari и Firefox Playwright не ведёт). У каждого браузера свои папки профилей программы.
- `bookprice/window.py` — окно программы: браузер в режиме приложения с отдельным профилем, то есть свой процесс.
  Своим считается только процесс, у которого в командной строке профиль программы **и** который держит замок этого
  профиля (`lockfile` на Windows, `SingletonLock` на Mac): Edge, запущенный через `cmd /c start`, уходит в профиль
  пользователя, сохраняя нашу командную строку. Яндекс после закрытия окна перезапускается в фоне
  (`--no-startup-window`) — такие процессы своего профиля программа добирает.
- `bookprice/system/` — всё, что различается между Windows и macOS (`windows.py`, `mac.py`: папки, процессы, окна
  сообщений, сертификаты); остальной код общий и про систему не знает.
- `bookprice/app.py`, `bookprice/ui/` — локальный сервер на 127.0.0.1:8769 и интерфейс;
  `store.py` — SQLite.
- `bookprice/check.py` — проверка площадок со снимками страниц (кнопка в «Справке»).
- `bookprice/updater.py` + `run.py` — обновления: самый свежий опубликованный выпуск (тег `vX.Y.Z`) для своей
  системы скачивается в `updates` папки данных, запуск берёт самую свежую совместимую версию, но не старее своей.
  Строка «Система: только macOS» (или «только Windows», «Windows и macOS») в `docs/releases/X.Y.Z.md` говорит,
  кому выпуск; без неё — всем. Нумерация версий общая. Если обновлению нужны новые пакеты — поднять
  `REQUIRES_RUNTIME` (Windows) или `REQUIRES_RUNTIME_MAC` и выпустить новую сборку.
- Обновление работает на той программе, которую пользователь когда-то распаковал, а PyInstaller кладёт в неё
  только модули, импортированные кодом той сборки (в сборках до 0.2.2 нет даже `ctypes.wintypes`).
  `tests/test_runtime.py` сверяет все импорты кода со списком модулей, общих для всех выпущенных сборок
  (`tests/runtime1_modules.txt`, получен `python tools/runtime_modules.py ../dist/BookPrice-*.zip`).
  Модуль не из списка — обойтись без него или поднять `REQUIRES_RUNTIME`.
- Сборка: `python tools/build.py` (нужны `playwright` и `pyinstaller`), результат — в `../dist`. На Mac — там же,
  `Ценитель.app` и `.dmg`; окружение для универсальной сборки (Intel + Apple M) — `bash tools/mac/env.sh`.
- GitHub Actions (`.github/workflows/ci.yml`): тесты на Windows и macOS, сборка Mac-программы, проверка от запуска до
  выхода рядом с «пользовательским» Chrome (`tools/mac/smoke.py`), к опубликованному выпуску — `.dmg`. Логи и снимки
  экрана — в ветке `ci-results`.
- Выпуск: поднять `__version__`, написать `docs/releases/X.Y.Z.md`, коммит, тег `vX.Y.Z`, push тега,
  `python tools/release.py [--prerelease]` — релиз с архивом и инструкцией. Токен GitHub (fine-grained,
  Contents: write только на этот репозиторий) — в `~/.github/book-price.token`.
- Отладка: `BOOKPRICE_ONLY=chitai_gorod,alib` — искать только на перечисленных площадках.
- Разбор присланной проверки площадок: `python tools/replay.py проверка-площадок-….zip` — прогоняет
  текущие извлекатели по снимкам страниц офлайн и печатает, что найдено и какой вышел бы вердикт.
- Тесты: `python -m unittest discover -s tests -t .` Разбор внутри Edge пропускается без Playwright.

Python 3.9 и новее.
