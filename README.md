# Ценитель

Лисья оценка книг для Авито.


Программа для Windows: вводишь книгу — она смотрит цены в магазинах и на Авито и подсказывает,
за сколько выставить объявление и как снижать цену, если книга не продаётся.

Поиск идёт с компьютера пользователя через установленный Edge: Авито и магазины пускают обычных
посетителей, а серверы — нет. Никакого ИИ: издание определяется по ISBN, объявления отбираются
фильтром, сомнительные человек отмечает сам.

## Как пользоваться

1. Скачать `BookPrice-<версия>.zip` из [Releases](https://github.com/AlexLion89/book-price/releases).
2. Правой кнопкой по архиву → «Извлечь всё…» (например, в «Документы», не во временную папку).
3. Открыть `BookPrice.exe` в распакованной папке. Windows один раз предупредит («Windows защитила
   ваш компьютер») — «Подробнее» → «Выполнить в любом случае». На рабочем столе появится ярлык
   «Ценитель».

Данные (книги, цены, журнал) лежат в `%LOCALAPPDATA%\BookPrice` и не зависят от папки программы.
Инструкция с картинками на два листа — [docs/instruction.pdf](docs/instruction.pdf).

## Для разработки

- `bookprice/pricing.py` — правило цены и график снижения.
- `bookprice/matching.py` — «то же издание или нет» для объявлений.
- `bookprice/catalog.py` — карточка книги по ISBN (FantLab + Читай-город) и поиск изданий по названию.
- `bookprice/sources/` — по модулю на площадку: `chitai_gorod`, `alib`, `fantlab` (HTTP),
  `avito`, `shops` (в Edge: маркетплейсы Озон, Wildberries, Маркет и книжные Лабиринт, Book24, Буквоед,
  Республика, Библио-Глобус), `extract` — разбор внутри страницы.
- `bookprice/value.py` — досье и надбавка за редкость (давно не переиздавалась, мало объявлений, спрос
  по рейтингу FantLab/Читай-города, коллекционные признаки), только к начальной цене, не больше +50 %.
- `bookprice/copymarks.py` — отметки экземпляра (автограф, первое издание, штампы…): к старту и пределу.
- `bookprice/sources/ratings.py` — оценки читателей LiveLib и ЛитРес через окно поиска (schema.org aggregateRating),
  один раз на книгу.
- `bookprice/search.py` — обход площадок и вердикт; `browser.py` — окно поиска Edge, капча, снимки
  (закрывается после каждого поиска).
- `bookprice/window.py` — окно программы: Edge в режиме приложения с отдельным профилем, то есть свой процесс;
  находится по папке этого профиля (Edge может передать запуск другому своему процессу) и никогда не трогает
  собственный Edge пользователя.
- `bookprice/app.py`, `bookprice/ui/` — локальный сервер на 127.0.0.1:8769 и интерфейс;
  `store.py` — SQLite.
- `bookprice/check.py` — проверка площадок со снимками страниц (кнопка в «Справке»).
- `bookprice/updater.py` + `run.py` — обновления: последний опубликованный релиз (тег `vX.Y.Z`) скачивается в
  `%LOCALAPPDATA%\BookPrice\updates`, запуск берёт самую свежую совместимую версию. Если обновлению
  нужны новые пакеты — поднять `REQUIRES_RUNTIME` и выпустить новый zip.
- Обновление работает на той программе, которую пользователь когда-то распаковал, а PyInstaller кладёт в неё
  только модули, импортированные кодом той сборки (в сборках до 0.2.2 нет даже `ctypes.wintypes`).
  `tests/test_runtime.py` сверяет все импорты кода со списком модулей, общих для всех выпущенных сборок
  (`tests/runtime1_modules.txt`, получен `python tools/runtime_modules.py ../dist/BookPrice-*.zip`).
  Модуль не из списка — обойтись без него или поднять `REQUIRES_RUNTIME`.
- Сборка: `python tools/build.py` (нужны `playwright` и `pyinstaller`), результат — в `../dist`.
- Выпуск: поднять `__version__`, написать `docs/releases/X.Y.Z.md`, коммит, тег `vX.Y.Z`, push тега,
  `python tools/release.py [--prerelease]` — релиз с архивом и инструкцией. Токен GitHub (fine-grained,
  Contents: write только на этот репозиторий) — в `~/.github/book-price.token`.
- Отладка: `BOOKPRICE_ONLY=chitai_gorod,alib` — искать только на перечисленных площадках.
- Разбор присланной проверки площадок: `python tools/replay.py проверка-площадок-….zip` — прогоняет
  текущие извлекатели по снимкам страниц офлайн и печатает, что найдено и какой вышел бы вердикт.
- Тесты: `python -m unittest discover -s tests -t .` Разбор внутри Edge пропускается без Playwright.

Python 3.9 и новее.
